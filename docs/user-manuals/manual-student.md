# Appendix E — User Manuals

## Student Manuals

**Purpose:** View courses and assignments, submit work, see released marks. Marks appear only after HoD release (BR4, BR6).

### Menu

1\. My courses
2\. Assignments in a course
3\. Submit / resubmit
4\. View submission for assignment
5\. View released marks
6\. Change password
0\. Logout

### Key Tasks

| Task | Menu | Inputs | Notes |
| --- | --- | --- | --- |
| See my courses | `1` | — | Course id needed for step 2 |
| See assignments | `2` | Course id | Extensions shown as `[EXTENDED -> …]` |
| Submit work | `3` | Assignment id, content | Confirms on-time or late |
| Resubmit before deadline | `3` again | Same assignment id | Latest submission replaces prior |
| Check submission | `4` | Assignment id | If released, shows mark + feedback |
| See released marks | `5` | — | Lists every released submission |

### How Your Mark Is Calculated

| Days late | Effect on mark |
| --- | --- |
| On time | Full mark entered by lecturer |
| 1 day | −10% of maximum |
| 2 days | −20% of maximum |
| 3 days | −30% of maximum |
| > 3 days | 0 — but work accepted and feedback written |

If your mark is not visible, the HoD has not released it. Wait; do not email the lecturer — they cannot release it.

### Common Issues

| Problem | Action |
| --- | --- |
| Forgot password | Contact lecturer or IT officer to request admin reset |
| Submitted wrong file, deadline not passed | Resubmit via `3` |
| Extension not showing | Confirm with lecturer; ask IT if granted |
| Mark looks wrong | Contact lecturer first — they can request HoD return |

### Reminders

- **Save your work in your own files** — the LMS stores what you paste
- **Never share your password** — every action is logged against your account
- **Note assignment id and time** on submission for proof
